# TrendRadar · 关键词模板（手机推送场景）
# 用法：覆盖仓库 config/frequency_words.txt，把示例词组换成你真正关心的话题
#
# 文件分两个区域：
#   [GLOBAL_FILTER]  全局过滤：每行一个不想看到的词，命中的新闻直接排除
#   [WORD_GROUPS]    词组定义：每组第一行写 [组别名]，组内每行一个词（"或"关系）
#                    组与组之间用空行分隔；左侧带 # 的行都是说明，不生效
#
# 语法速查：
#   关键词              普通词，标题包含即匹配
#   /正则/              正则匹配（自动忽略大小写），如 /AI|大模型/ => AI
#   关键词 => 别名      给这一行指定显示名称
#   [组别名]            词组第一行，给整组指定显示名称
#   +关键词             必须词，所有必须词都命中才算匹配
#   !关键词             过滤词，仅在本组内排除
#   @数字               限制该组最多显示多少条
#
# ⚠️ 关键词太多会导致每次推送很长，手机端建议控制在 4~8 组、每组 3~6 个词
# ═══════════════════════════════════════════════════════════════
